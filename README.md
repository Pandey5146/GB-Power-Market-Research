# GB Power Market Research (2023–2025)

## Objective
This project studies the Great Britain electricity market using Elexon BMRS data.

## Current Progress
- Pulled fuel generation data from BMRS
- Cleaned and grouped fuel types
- Pulled system price data
- Merged fuel and price data into a master dataset
- Performed initial statistical analysis

## Tools
- Python
- pandas
- SQL (planned)
- Power BI (planned)
- Streamlit (future)
